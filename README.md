# Telegram Media Downloader — آرشیو تلگرام 📥

برنامهٔ دسکتاپ (ویندوز) برای **دانلود کامل تاریخچهٔ چت‌ها و گروه‌های تلگرام**:

- ورود با شمارهٔ موبایل (کد + رمز دومرحله‌ای)
- نمایش همهٔ چت‌ها، گروه‌ها و کانال‌ها
- دانلود **از اولین پیام تا آخرین پیام**، مرتب و **بدون پیام تکراری**
- دانلود همهٔ فایل‌ها: عکس، ویدیو، صوت، ویس، استیکر و سند (در پوشه‌های جدا)
- **ادامه‌پذیری**: اگر وسط کار قطع شود، از همان‌جا ادامه می‌دهد
- خروجی HTML به سبک خروجی دسکتاپ تلگرام با تاریخ شمسی (قابل اجرا در مرورگر)
- **ساخت اپ اندروید** از خروجی (پروژهٔ WebView + ZIP)
- رابط گرافیکی تیره و تمیز + **لاگ کامل**

---

## نصب (یک‌بار)

1. **پایتون ۳.۱۰ یا بالاتر** نصب کنید: از [python.org](https://www.python.org/downloads/)
   — در صفحهٔ نصب حتماً گزینهٔ **Add Python to PATH** را تیک بزنید.
2. در پوشهٔ پروژه (جایی که فایل‌های برنامه را گذاشته‌اید) ترمینال باز کنید:
   ```
   pip install -r requirements.txt
   ```
3. از سایت [my.telegram.org](https://my.telegram.org) وارد شوید:
   - منوی **API development tools** → یک اپ جدید بسازید
   - مقدارهای **api_id** و **api_hash** را کپی کنید (این‌ها متعلق به خودتان است و امن است)

## اجرا

```
python run.py
```

- در صفحهٔ «ورود» سه مقدار api_id، api_hash و شمارهٔ موبایل را وارد کنید.
- کد پیامک‌شده را بزنید (در صورت داشتن رمز دومرحله‌ای، آن را هم).
- به «چت‌ها» بروید، چت/گروه موردنظر را دوبار کلیک کنید.
- «شروع دانلود» → از اول تا آخر همه‌چیز دانلود می‌شود. بعد از پایان، خروجی HTML خودکار ساخته می‌شود.

> نکته: اگر با تلگرام محدودیت (FloodWait) داشتید، برنامه خودش صبر می‌کند و ادامه می‌دهد.

## ساخت اپ اندروید

1. بعد از دانلود، به صفحهٔ «اپ اندروید» بروید و «ساخت اپ اندروید» را بزنید.
   پروژهٔ اندروید + فایل ZIP کنار خروجی ساخته می‌شود.
2. [Android Studio](https://developer.android.com/studio) را نصب کنید، پروژه را باز کنید
   و از منوی **Build → Build APK** خروجی بگیرید.
3. APK را روی گوشی نصب کنید — همهٔ پیام‌ها و فایل‌ها **داخل خود اپ** است و به اینترنت نیاز ندارد.

هر بار که دوباره بسازید، پروژهٔ جدید با **نام یکتا** ساخته می‌شود؛
پس هیچ خطای «آپدیت/تداخل» پیش نمی‌آید و چند خروجی با هم تداخل ندارند.

## ساختار پوشهٔ خروجی

```
TelegramMediaDownloader Exports/
└── Matin_Uchiha_export/          ← نام حساب شما
    ├── index.html                ← لیست چت‌ها
    ├── assets/                   ← استایل و اسکریپت
    └── chats/
        └── نام_چت/
            ├── index.html        ← تاریخچهٔ چت
            ├── photos/  videos/  audio/  documents/  stickers/
            ├── messages.jsonl    ← همهٔ پیام‌ها (فرمت JSON)
            └── state.json        ← وضعیت دانلود (برای ادامه)
```

## تست آفلاین

بدون اینترنت و بدون تلگرام، صحت خروجی‌ها را بررسی کنید:

```
python selftest.py
```

## حل مشکلات

| مشکل | راه‌حل |
|---|---|
| «python پیدا نشد» | پایتون را نصب و Add to PATH را تیک بزنید؛ ترمینال را ببندید و دوباره باز کنید |
| ورود کار نمی‌کند | api_id/api_hash را از my.telegram.org دوباره بگیرید؛ برای ایران بهتر است فیلترشکن روشن باشد |
| محدودیت FloodWait | برنامه خودش صبر می‌کند؛ چت‌های سنگین را شب یا با فاصله دانلود کنید |
| خروج از حساب | فایل `%APPDATA%\TelegramMediaDownloader\sessions\telegram.session` را پاک کنید |
| لاگ‌ها کجاست؟ | داخل برنامه صفحهٔ «لاگ» + فایل `%APPDATA%\TelegramMediaDownloader\logs\app.log` |

> توجه: از این ابزار فقط برای چت‌ها و فایل‌هایی استفاده کنید که مجاز به نگه‌داشتنشان هستید.
